# Atributos de Calidad

## 1. Seguridad

AulaViva debe proteger los datos de estudiantes y docentes, evitando accesos no autorizados y manteniendo aislada la información de cada institución.

## 2. Escalabilidad

La plataforma debe poder soportar un aumento de usuarios y evaluaciones, especialmente durante períodos de pruebas.

## 3. Disponibilidad

AulaViva debe mantenerse disponible para que estudiantes y docentes puedan utilizar la plataforma sin interrupciones importantes.
