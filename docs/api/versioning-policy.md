# Política de Versionado de API

## Versión actual

La API utiliza versionado mediante la URL.

La versión actual es:

`/api/v1`

## Cambios compatibles

Los cambios compatibles pueden incorporarse dentro de la misma versión.

## Cambios incompatibles

Los cambios que modifiquen de manera incompatible los contratos existentes requerirán una nueva versión de la API.

## Deprecación

Antes de retirar una versión, se deberá informar a los consumidores de la API y mantener la versión anterior durante un período de transición.

## Compatibilidad

Las respuestas y solicitudes existentes deberán mantenerse compatibles mientras la versión se encuentre vigente.
