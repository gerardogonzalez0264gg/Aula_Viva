# ADR 0001 - Elección de la iniciativa AulaViva

## Contexto

Para el desarrollo del taller se presentaron tres iniciativas:

- MediTriage - HealthTech.
- CrediScore - FinTech.
- AulaViva - EdTech.

Era necesario seleccionar una iniciativa para utilizarla como proyecto durante el semestre.

## Decisión

Se decidió desarrollar **AulaViva — Plataforma SaaS multi-tenant con tutor IA**.

La iniciativa consiste en una plataforma educativa orientada a colegios que permitirá gestionar cursos, docentes y estudiantes, realizar evaluaciones auto-corregidas y utilizar un tutor IA basado en los contenidos de cada curso.

## Justificación

AulaViva permite trabajar diferentes áreas de la ingeniería de software durante el semestre, incluyendo:

- Ingeniería de requisitos.
- Arquitectura de software.
- Desarrollo de APIs.
- Gestión de datos.
- IA y RAG.
- Seguridad.
- CI/CD.
- Testing.
- Observabilidad.
- Escalabilidad.

Además, el proyecto presenta desafíos técnicos relevantes, como el aislamiento de información entre colegios, la protección de datos de menores, la escalabilidad durante períodos de evaluaciones y el control de costos del uso de IA.

## Consecuencias positivas

- Permite desarrollar un producto educativo con diferentes tipos de usuarios.
- Permite incorporar funcionalidades de inteligencia artificial.
- Permite aplicar los contenidos de las distintas sesiones del taller.
- Permite trabajar requisitos funcionales y no funcionales.

## Consecuencias negativas

- El proyecto presenta una complejidad considerable debido a la incorporación de IA.
- Será necesario considerar el aislamiento de datos entre colegios.
- Se deberán considerar medidas especiales para la privacidad de los datos de menores.
- El uso de IA puede generar costos que deberán ser controlados.
